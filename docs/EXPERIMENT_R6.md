# R6 (00.14) — PT-BR experimental
Evidence: R5 received only 16 MiB of executable VM memory even with 111 MiB user memory free. D2Vita reports the same per-process quota (https://franckrst.github.io/D2Vita/changelog/). No new kernel plugin or VM quota patch is shipped. Default request 16 MiB; existing max override up to 48 MiB remains available. JIT pool usage reads no longer lock the allocator on every EE safe-point check. Emergency reserve bypasses cooldown at a safe EE discard point. The discard still clears EE code, not a full selective eviction redesign. Disk JIT index reserves bounded space and cached code reads reuse a 128 KiB window. New eboot => new cache; keep R5 files.
HLE: PS2SDK documents 0x4A SetOsdConfigParam and 0x6E/0x6F extended OSD settings. Implement round-trip state in reserved BIOS RAM words, preserving struct size; bounded four-byte extended record. No Sony BIOS distributed or loaded. SIF0 stop, SPU2 unknown registers, ROMVER, and IPU stalls require further behavioral verification; do not fake successful operations. No compatibility claim yet.
Every launch gets its own folder under ux0:data/VitaPS2exp/r6-logs/. r6-latest-game.txt and r6-latest-test.txt are separate pointers. Built-in gs_test no longer opens disk JIT; filenames sanitize device prefixes. EE/IOP hotspots and syscall/register diagnostics after 60 seconds, can set ee_hot_after=0; late GS trace after a 10-second stall past 60 seconds. PT-BR maintained. Existing safe JIT, EE region, indirect dispatch, fast RAM and MPEG HLE controls can be isolated in experiment.ini; no new VU allocator, no unverified timing changes forced. Tests need actual Vita hardware.
