# R4 (00.12) experimental Vita-only build
R3 session: SLUS-21224, cache cold, 9375 blocks stored, 24 VIF1 records, 2 quiet waits (287213 us), no output in final samples. Uploaded CSVs were byte-identical to R2, so there is no valid R3 FPS comparison. Restore IOP inline, VBlank VU1 synchronization and disable async VIF1 by default, keeping the known RE4 profile. Guitar Hero gets readback_finish=1 (accuracy experiment) and 16-bit NEON only after on-device differential selftest. No guarantee the stall was caused by any one R3 setting.

New code: group adjacent requested GPU blocks in order (max 16, no gaps or crossing rows); per-block texture invalidation preserved. Underlying upstream block_coherency remains OFF because it is not exact. JIT pool reuses map nodes without changing first-fit or coalescing; rejects alignment overflow. JIT writer uses 64 KiB stdio buffer, flushes header, retries failed flush rather than marking pending bytes committed. Throttle stall PC sampling to 10 Hz; direct session report includes thread affinities, clocks, game FPS and grouped readback counters. All R4 CSVs/session/GS logs prefixed r4-. Existing old logs remain untouched. No new app ID; overwrites R3.

A/B in experiment.ini: readback_finish=0, target_pixels_neon16=0, group_block_readbacks=0; tier2=1 and tier2_verify=1 are existing experimental core features, not a new compiler. Keep block_coherency=0 for ordinary play. No copying GPL code. No measured R4 FPS yet. Test cold once, warm again with same ISO/build.
